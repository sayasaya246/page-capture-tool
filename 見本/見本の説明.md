# 見本ページの説明

すべて自作の文章で、外部のURL・スクリプト・画像は使っていません。サーバーは `スクリプト\テスト\見本サーバー.py`（http://127.0.0.1:8765/）で起動します。

## どれが本文で、どれが広告か（全ページ共通）
| 要素 | セレクタ | 扱い |
|---|---|---|
| 本文 | `article#main-article` | 取り出す |
| 広告（上・サイド） | `.ad`（`#ad-top`、`#ad-side`） | 取り除く |
| サイドのカード | `aside .side-card`（筆者・ランキング） | 取り除く |
| 固定メニュー | `nav#fixed-menu`（画面上に固定） | 取り除く |
| フッター | `footer#site-footer` | 取り除く |
| Cookieバナー | `#cookie-banner`（cookie.html のみ） | 閉じてから取り出す |

## 補足
- 次へリンク型・ページ番号型・ボタン型は、3ページ目が最後です（最後に「次へ」は出ません）。
- 無限スクロール型の期待される最後は、本文の最後の文ではなく「これで終わり」の印（#end-mark）です。
- 遅延読み込み型は、スクロールして見えるまで本文が入りません（prepare でスクロールが必要）。
