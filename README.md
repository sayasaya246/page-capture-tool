# 画面PDF化アプリ

Webページの読みたい部分だけを取り込み、文字入りのPDFと Markdown にする、Windows 向けの個人用ツールです。

- ブラウザで開いたページ（ログインが必要なページを含む）から、本文だけを取り出します。
- 広告やメニューは外します。ページ送り（次へ・番号・スクロール）にも対応します。
- 作ったファイルには、作成者・日時・出典の URL を入れます。
- 処理はすべて自分のPCの中で行い、外部のサービスには送りません。
- コピー禁止の仕組みや、確認画面（CAPTCHA）は突破しません。見つけたら止まります。

## 動かすための準備

1. Python 3.12 を入れます。
2. 次のコマンドで、部品を入れます。

```
python -m pip install -r requirements.txt
python -m playwright install chromium
```

## 起動

```
python -X utf8 app.py
```

## 設定

設定ファイル（config.json）の中で、保存先や、ページ待ち秒、最大ページ数などを変えられます。設定ファイルの場所は、環境変数 `GAMEN_PDF_CONFIG` で指定します。

Drive（G:）が使えないときの代わりの場所は、環境変数 `GAMEN_PDF_DRIVE_MIRROR` で指定します。指定しないときは、このフォルダの3つ上を使います。

## テスト

見本ページ（`見本` フォルダ）を、ローカルの見本サーバーで配って確かめます。

```
cd テスト
python -X utf8 run_tests.py
python -X utf8 run_pipeline_tests.py
```

## フォルダの中身

| ファイル | 役割 |
|---|---|
| app.py | 画面（tkinter） |
| pipeline.py | 取り込みの流れをつなぐ |
| web.py | ブラウザの操作と本文の取り出し |
| paginate.py | ページ送り |
| range_select.py | 読みたい部分の指定（クリックで覚える） |
| output.py | Markdown と PDF の書き出し |
| common.py | 設定、ファイル名、データの形、停止の例外 |
| テスト\ | 見本サーバーと、テストの実行 |
| 見本\ | テスト用の見本ページ（自作） |

## 注意

- 個人利用に限ります。利用規約で禁止されたサイトや、大量の取得には使わないでください。
- ログイン情報は、専用のブラウザのプロファイルに保存されます。このリポジトリには含めません。
